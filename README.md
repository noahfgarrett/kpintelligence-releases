# KPIntelligence releases

Installers and signed update files for [KPIntelligence](https://github.com/noahfgarrett/kpintelligence), a local-first desktop app for Windows and macOS that turns synced SharePoint and OneDrive spreadsheets into dashboards, PDF reports, and PowerPoint decks.

Download the [latest release](https://github.com/noahfgarrett/kpintelligence-releases/releases/latest). Installed copies read `latest.json` from the latest release to find updates. The source code lives in the main repo.
